Desktop architecture

Stock COSMIC 1.11, nothing in its way

Native Rust Wayland compositor, built-in per-workspace auto-tiling, native apps, and plain RON configuration files. Cosmarchy deploys behaviour defaults and leaves appearance to COSMIC Settings and cosmic-initial-setup.

🚀

Plain RON config, zero hidden state

COSMIC stores every setting as a plain file under ~/.config/cosmic/. The installer deploys Cosmarchy's auto-tiling, shortcuts, and chosen keyboard layout directly inside the chroot — no session daemon workarounds required.

🧩

Built-in compositor auto-tiling

cosmic-comp tiles windows natively with autotile = true and PerWorkspace behavior. Toggle per workspace with Super + Y or float a single window with Super + G.

🛡️

Bootable Btrfs snapshots

The installer lays out @, @home, @snapshots, @var_log, and @var_cache on Btrfs with Snapper and snap-pac. Every snapshot appears in the COSMIC Dark Limine menu with its own kernel and promotes back to root with cosmarchy snapshot restore.

Session COSMIC 1.11 · Wayland · greetd (cosmic-greeter)
Filesystem Btrfs subvolumes, LUKS2 optional
Bootloader Limine (COSMIC Dark) + Snapper
Phone & Apps KDE Connect · Brave Origin · VS Code · Flatpak
Window management

Per-workspace auto-tiling built right in

COSMIC ships automatic tiling directly inside cosmic-comp — directional focus, window stacking, orientation switching, and floating exceptions without a single shell extension.

cosmarchy tiling status

Instant CLI control

cosmarchy tiling enable, disable, and toggle write atomically to ~/.config/cosmic/com.system76.CosmicComp/v1/autotile, which cosmic-comp watches and applies live.

Every workspace keeps its own tiling toggle thanks to autotile_behavior: PerWorkspace.

          Games and hardware
          
A gaming stack and laptop controls, on demand

          

            Neither bloats the base image; both are ready when you want them.
          

        


        

          

            cosmarchy gaming install
            
Steam, Proton-GE and the rest

            

              Enables multilib, detects the GPU vendor and installs only the matching 32-bit Vulkan
              driver, then pulls the stack from the official repositories.
            

            
steam · lutris · gamescope
gamemode · mangohud · goverlay
wine · winetricks · vkd3d
umu-launcher · ttf-liberation

            

              Proton-GE, ProtonUp-Qt and Faugus Launcher come from the AUR, with a Flatpak fallback
              when no AUR helper is present. cosmarchy gaming proton manages versions.
            

          


          

            cosmarchy asus
            
Asus ROG and TUF laptops

            

              A front end over asusctl and supergfxctl for the settings
              worth changing day to day, so the common cases are one obvious command.

profilequiet / balanced / performance

              
keyboard medkeyboard backlight

              
statusmodel, asusd, supergfxd

            

            

              Reports clearly when asusctl is missing or asusd is not
              running rather than failing quietly.

    • 
              
  • Inference — whisper-cpp on the CPU. A GPU backend means adding ggml-vulkan yourself

          Deployment
          
Install Cosmarchy

          

            Seven stages: partition Btrfs, install Arch and COSMIC 1.11, deploy RON configs and
            Limine, and record snapshot 1.
          

        


        

          

            Method 1 · recommended
            
Bootable ISO

            

              Write the ISO to a USB stick and boot it. The gum installer lays out Btrfs subvolumes,
              optionally sets up LUKS2, installs Limine + Snapper, and deploys stock COSMIC 1.11
              on cosmic-greeter.
            


            

              
                Download from GitHub Releases
              
            


            
# Every release ships a SHA256SUMS file
sha256sum -c SHA256SUMS

# Flash it (replace /dev/sdX)
sudo dd if=cosmarchy-linux-*-x86_64.iso of=/dev/sdX bs=4M status=progress

          


          

            Method 2 · over existing Arch
            
Deploy onto a minimal Arch install

            

              Already have a clean Arch system? The same staged installer runs on top of it and
              installs COSMIC, the developer tooling, and the CLI without touching your partitions.
            


            
curl -fsSL https://cosmarchy.pages.dev/install | bash


            

              Prefer to try it first? Clone the repository and run ./run-vm.sh to boot
              the ISO under QEMU. CI builds the ISO, installs from it in a QEMU virtual machine,
              and verifies both the offline image and a live COSMIC Wayland session.
            

          

        


        

          

            After the install
            cosmarchy update pulls the repo, refreshes boot tooling, and runs pending migrations
          

          

            If something looks wrong
            /var/log/cosmarchy-installer.log shows the failing stage; /var/log/cosmarchy-install.log carries per-stage markers
